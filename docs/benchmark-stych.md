# Benchmark — appli élève Stych (iOS)

Source : 3 captures d'écran transmises par le client le 11/11/2026 (Accueil, Menu, Mon compte), compte d'une élève réelle. Les captures ne sont **pas** stockées dans le dépôt (données personnelles). On reprend des **fonctions**, jamais le visuel, les textes ou la mascotte (voir le plan : pas de copie).

## Ce qu'on voit

**Onglets** : Accueil · Planning · Mon compte · Messagerie (avec pastille de non-lus) · Menu.

**Accueil** :
- un grand bandeau d'incitation (« réviser le code ») avec un bouton jaune ;
- un bloc **Code** : pourcentage de progression + 3 raccourcis (continuer à réviser, examen blanc, réserver sa place d'examen) ;
- un bloc **Conduite** : pourcentage de progression + 3 raccourcis (tableau de bord, réserver ses leçons, réserver sa place d'examen) ;
- « Formations complémentaires » (vente d'autres formations).

**Menu** : Formations · Planning · Contactez-nous · Dossier d'inscription préfectoral · Mon compte · Factures · assistant IA · Défi code · Parrainage.

**Mon compte** : profil · Documents · Factures · Communications (préférences de notifications) · Gestion des données (RGPD) · Restaurer les achats in-app · À propos · Déconnexion.

## Ce qu'on ne reprend pas

- **L'habillage** : barre bleue « maison », mascotte, bouton jaune plein écran. C'est l'identité de Stych et ça ne respecte pas les codes natifs iOS / Android, qui sont une exigence du client.
- **Les doublons** : Planning est à la fois un onglet et une entrée du menu, Factures est à la fois dans Menu et dans Mon compte. Chez nous, une fonction a une seule place.
- **Un onglet entier pour « Mon compte »** : chez nous le compte est dans « Mes infos », qui contient aussi la fiche d'identité demandée par le Word.
- **Un pourcentage de conduite sans explication** (« 84 % ») : on garde la progression par compétence C1 à C4, rattachée au livret, que l'élève et l'enseignant comprennent.
